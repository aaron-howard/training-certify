# Project history

Brief history and milestones for Training Certify.

## Origin

Training Certify started as a product plan and design (Design OS methodology), then was implemented as a full-stack application for managing training certifications, team requirements, and compliance.

## Milestones

- **Product design** — Vision, roadmap, data model, and UI sections defined (certification management, catalog, teams, compliance, notifications).
- **Implementation** — TanStack Start, React 19, Drizzle ORM, PostgreSQL, Clerk authentication.
- **Production hardening** — CSRF, rate limiting, security headers, health/ready endpoints, Sentry, metrics, deployment and troubleshooting docs.
- **Testing** — Unit and API tests with coverage gates, Playwright E2E, CI (test, lint, type-check, build, e2e, security scan).
