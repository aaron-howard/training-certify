- **Q&A and discussions:** [GitHub Discussions](https://github.com/aaron-howard/training-certify/discussions) — ask and answer questions in the Q&A category.
- **Bugs and features:** [GitHub Issues](https://github.com/aaron-howard/training-certify/issues) — report bugs or request features (check existing issues first).

## Bugs

When reporting a bug, please include:

- Steps to reproduce
- Expected vs actual behavior
- Environment (OS, Node version, pnpm version, etc.)

Use the [bug report template](.github/ISSUE_TEMPLATE/bug_report.md) when opening an issue.

## Feature ideas

Open an issue with the `enhancement` label and describe the idea, use case, and impact. For large changes, starting a Discussion first is helpful.
